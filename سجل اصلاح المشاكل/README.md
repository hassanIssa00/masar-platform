# سجل اصلاح المشاكل

آخر تحديث: 2026-09-02

## 1. مشكلة الطالب لا يظهر في إدارة الطلاب

المشكلة:
كان إنشاء حساب طالب أو توليد حسابات أحياناً يحفظ الحساب فقط، أو يحفظ ملف طالب غير مكتمل، ثم لا يظهر بشكل ثابت في صفحة إدارة الطلاب.

الإصلاح:
- تم نقل التخزين العملي إلى `cloudStore` وربط الحفظ بمجموعات Firestore.
- تم التأكد أن توليد الحسابات يكتب ملف الطالب في مجموعة `students`.
- تم توسيع مفاتيح المزامنة المستخدمة في صفحات الطلاب والتقارير.
- تم إبطال كاش snapshot بعد عمليات الحفظ والحذف.

الملفات الأساسية:
- `src/lib/cloudStore.ts`
- `src/lib/firestoreSync.ts`
- `src/app/api/accounts/generate/route.ts`
- `src/app/api/data/snapshot/route.ts`
- `src/app/students/page.tsx`

- تم منع fallback خطر كان يختار أول طالب إذا لم يجد مطابقة.

المشكلة:

الإصلاح:

- حساب ولي الأمر يظل محتاج استكمال حتى تكون بيانات الطالب مكتملة ويوجد استبيان محفوظ.
- حساب الطالب يظل محتاج استكمال حتى تكون بيانات الطالب مكتملة ويوجد اختبار طالب محفوظ.
- التسجيل العادي وجوجل وآبل وحسابات التوليد تدخل أولاً إلى `/student/new` ثم `/survey` أو `/assessment` حسب الدور.

الإصلاح:

## 11. إصلاح شامل لمسار تسجيل الدخول والاستبيان وصفحة البيانات

المشكلة:
- صفحة ملء البيانات كانت تظهر كل مرة يسجل فيها ولي الأمر دخوله لأن `onboardingRequired` كان يُحفظ بقيمة `true` حتى بعد إكمال البيانات.
- الاستبيان كان لا يظهر لأن صفحتي ولي الأمر (parent وschool-parent) كانتا تعرضان لوحة التحكم مباشرة بدون التحقق من وجود استبيان.
- الحسابات المولدة (توليد الحسابات) كانت تعدّي ولي الأمر مباشرة للبوابة بدون ملء بيانات أو استبيان.
- صفحة البيانات كانت تطلب اسم الطالب وصورته من ولي الأمر حتى لو الطالب مربوط بالفعل من التوليد.
- الطالب بحساب مولد كان يدخل مباشرة لصفحة الطالب بدون ملء بيانات.

الإصلاح:
- تم إصلاح `onboardingRequired: true` ← `false` في `student/new/page.tsx` بعد حفظ البيانات (كانت دي البق الأساسية).
- تم إعادة كتابة `redirectAfterLogin` في `auth/login/page.tsx`:
  - الطالب: لو اسمه placeholder أو `onboardingRequired=true` → صفحة إكمال البيانات.
  - ولي الأمر: لو مفيش طالب أو اسم الطالب placeholder → صفحة البيانات → ثم الاستبيان → ثم البوابة.
- تم إضافة redirect guards في `school-parent/page.tsx` و`parent/page.tsx`:
  - لو مفيش استبيان → redirect لصفحة الاستبيان.
  - لو مفيش طالب مربوط → redirect لصفحة البيانات.
- تم إضافة redirect guard في `school-student/page.tsx`:
  - لو اسم الطالب placeholder → redirect لصفحة إكمال البيانات.
- تم تحسين `student/new/page.tsx` للحسابات المولدة:
  - لو ولي الأمر عنده `linkedStudentId` من التوليد → الطالب يعتبر "مربوط" والفورم يعرض فقط حقول ولي الأمر (اسم ولي الأمر، الهاتف، الهوية، ملاحظات) بدون طلب اسم/صورة الطالب.

الملفات الأساسية:
- `src/app/auth/login/page.tsx` — إعادة كتابة redirectAfterLogin
- `src/app/student/new/page.tsx` — إصلاح onboardingRequired + دعم الحسابات المولدة
- `src/app/school-parent/page.tsx` — إضافة redirect guard للاستبيان
- `src/app/parent/page.tsx` — إضافة redirect guard للاستبيان
- `src/app/school-student/page.tsx` — إضافة redirect guard لإكمال البيانات
